## 背景与目标

| 角色 | 主机 | 目录 |
|------|------|------|
| **正式** | `47.110.57.118` | `/opt/backpack-quant` |
| **测试** | `39.106.143.222`（现网） | `/opt/backpack-quant` |

- 正式机用 **Docker Compose**（`api:8100` / `webhook:8005`），前端由 **api 容器静态资源**提供。  
- **停掉**正式机旧栈（`/opt/trading/ending/...` 等占用 8100/8005/8050 的进程）。  
- **DB**：接正式机**已有 MySQL**（不启 compose 内 mysql，或 profile 关掉）。  
- **Clash/mihomo**：宿主机长期跑；容器只配 `HTTP(S)_PROXY`。  
- **Nginx**：保留 `mulonghk.com`、443 证书与现有 location；只做最小 `proxy_pass` 调整。  
- **CI**：两套 workflow + 两套 Secrets（正式 / 测试）。

### TradingView HTTPS Webhook（定稿）

对外仍用 `https://47.110.57.118/...` → Nginx → 宿主机 `8005`/`8100`。Docker 只负责监听端口，**不改变 TV 警报 JSON**。若警报 URL 仍指向旧机 IP，迁正式后改主机名即可。

### 验收标准（全部）

1. `curl -sf https://47.110.57.118/api/health`（或经 443 Nginx）返回 ok  
2. 浏览器打开正式前端（443 `/` → api 静态）可登录/打开策略页  
3. TV → HTTPS webhook 路径仍通（`/webhook`、`/adaptive-long/webhook` 等 → 8005）  
4. `mulonghk.com`（80）与其它站点无回归  
5. 容器内经代理可 `curl -x $HTTPS_PROXY https://fapi.binance.com/fapi/v1/ping`

## 任务拆解

### T1：compose 支持「外部 MySQL + 宿主机代理」

- **文件**: `docker-compose.yml`, `deploy/env.example`,（可选）`docker-compose.prod.yml`  
- **改动**:  
  - 正式机 **不启动** `mysql` 服务（`profiles: [local-mysql]` 或独立 override）。  
  - `api`/`webhook`/`dingtalk-agent` 的 `DB_HOST` 改为读 `.env`（不再写死 `mysql`）。  
  - 增加代理环境变量透传：`HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`（示例：`http://172.17.0.1:7891`）。  
  - `extra_hosts` 或文档说明 Docker bridge 访问宿主机方式。  
- **验证**: `docker compose config` 无语法错误；本地用假 `.env` 能解析。  
- **完成标准**: 正式 `.env` 填外部 DB + 代理后，可不启 mysql 容器起 api。

### T2：正式机引导脚本（停旧栈 + 目录 + mihomo 检查）

- **文件**: `deploy/bootstrap-prod-47.sh`（新建）,（可选）`deploy/README-prod.md`  
- **改动**:  
  - 创建 `/opt/backpack-quant`。  
  - 检测并提示停止占用 `8100/8005/8050` 的旧进程（不自动杀 `nginx`/`mihomo`）。  
  - 检查 `ss -tlnp | grep 7891`；指引 `tools/proxy/start_clash.sh`。

- **验证**: `bash -n deploy/bootstrap-prod-47.sh`

### T3：Nginx 最小改动清单（人工执行，脚本只备份/diff）

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 停旧栈导致现网中断 | 选低峰；先备份 Nginx；保留旧目录不删 |
| Docker 访问宿主机 MySQL/代理失败 | 先测 `172.17.0.1`；必要时 `network_mode`/`extra_hosts: host.docker.internal` |
| 正式误部署 | 正式 workflow 默认仅 `workflow_dispatch` |
| TV webhook 404 | 对照现有 location 列表逐条测；保留 `/webhook`→8005 |
| 密钥进仓 | `.env` / 订阅 URL 永不进 Git；`start_clash.sh` 内 DEFAULT 订阅勿提交新值 |

回滚：Nginx 恢复备份 conf；`docker compose down`；必要时临时拉起旧 `/opt/trading/ending` 进程。
