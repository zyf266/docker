## 一、Python 与 Web 框架（1～15）

### 1. Python 中 list 和 tuple 的区别？什么场景用 tuple？

**A：** list 可变，tuple 不可变；tuple 可做 dict 键、更省内存；固定结构数据（坐标、配置项）用 tuple。

### 2. 深拷贝和浅拷贝的区别？

**A：** 浅拷贝只复制外层引用；深拷贝递归复制。`copy.copy()` vs `copy.deepcopy()`。嵌套对象共享引用时浅拷贝会互相影响。

### 3. GIL 是什么？对多线程有什么影响？

**A：** CPython 全局解释器锁，同一时刻只有一个线程执行字节码；I/O 等待时会释放；CPU 密集适合多进程，I/O 密集多线程仍有效。

### 4. ⭐ 多线程、多进程、asyncio 协程如何选择？

**A：** CPU 密集→多进程；I/O 密集→多线程或 asyncio；高并发连接→asyncio + 非阻塞 I/O。模型推理若 CPU/GPU  bound 常单独进程/容器。

### 5. ⭐ FastAPI 和 Django/Flask 的区别？药物研发 API 为什么可能选 FastAPI？

**A：** FastAPI：ASGI、原生 async、Pydantic 校验、自动 OpenAPI，适合 ML 推理网关；Django：全栈 ORM/Admin，适合复杂业务 CRUD；Flask：轻量灵活。推理接口需要 async + 类型校验 + 文档时 FastAPI 常见。

### 6. FastAPI 依赖注入 `Depends` 的作用？

**A：** 声明式解析依赖（DB Session、鉴权、配置），便于测试替换 Mock。

### 7. Pydantic 在 API 层解决什么问题？

**A：** 请求/响应数据校验与序列化，非法输入在进业务前拦截，减少脏数据进 ML pipeline。

### 8. Django ORM 的 N+1 问题是什么？如何解决？

**A：** 循环访问关联对象导致多次 SQL；用 `select_related`（FK）、`prefetch_related`（M2M）预加载。

### 9. Flask 应用工厂模式有什么好处？

**A：** 便于多环境配置、测试时创建独立 app 实例、扩展延迟初始化。

### 10. Python 装饰器的作用？在 API 里常见用途？

**A：** 闭包增强函数；用于鉴权、日志、限流、重试、计时。

### 11. `*args` 和 `**kwargs` 的作用？

**A：** 可变位置参数（元组）和可变关键字参数（字典）；用于通用封装、装饰器。

### 12. Python 垃圾回收机制？

**A：** 引用计数为主；标记-清除处理循环引用；分代回收优化扫描。

### 13. 生成器和列表推导式的区别？

**A：** 生成器惰性求值、省内存；大数据流式处理（ETL 读大文件）适合生成器。

### 14. 如何在 Python 中调用 C/Go 扩展或 GPU 库？

**A：** ctypes/cffi、Cython；或通过 gRPC/HTTP 调独立推理服务（生产更常见）。

### 15. ⭐ 如何用 Python 包装一个 ML 模型对外提供 HTTP 服务？

**A：** FastAPI 加载模型（startup 事件）→ POST `/predict` 接收 JSON → 预处理 → `model.predict` → 返回 JSON；超时、批处理、模型版本、健康检查 `/health`。

## 二、RESTful API 与微服务（16～27）

### 16. ⭐ RESTful 设计原则？

**A：** 资源用 URI；HTTP 方法语义化（GET 查、POST 建、PUT/PATCH 改、DELETE 删）；无状态；统一 JSON 格式。

### 17. PUT 和 PATCH 的区别？

**A：** PUT 全量替换；PATCH 部分更新。

### 18. HTTP 状态码 200/201/400/401/403/404/500 分别表示什么？

**A：** 成功/创建/客户端参数错/未认证/无权限/不存在/服务端错误。

### 19. ⭐ 如何设计分页 API？

**A：** `page`+`page_size` 或 cursor 游标分页；返回 `total`、`items`；深分页用 cursor 避免 OFFSET 过大。

### 20. API 版本管理怎么做？

**A：** URL `/v1/`、Header `Accept-Version`、或网关路由；废弃版本提前公告。

### 21. ⭐ 微服务和单体架构的优缺点？

**A：** 微服务：独立部署、技术栈灵活、故障隔离；缺点：分布式复杂度、链路追踪、数据一致性。AI 推理、ETL、业务 CRUD 可拆服务。

### 22. 服务之间如何通信？

**A：** 同步 HTTP/gRPC；异步消息队列（Kafka/RabbitMQ）；药物场景长任务常用异步+轮询/Webhook。

### 23. ⭐ gRPC 和 REST 的区别？何时用 gRPC？

**A：** gRPC：Protobuf、二进制、高性能、强类型、流式；REST：JSON、易调试、浏览器友好。内部服务间高频调用、流式推理用 gRPC。

### 24. 什么是 API Gateway？作用？

**A：** 统一入口：鉴权、限流、路由、SSL、聚合多个微服务。

### 25. 如何实现接口幂等性？

**A：** 幂等键（Idempotency-Key）；数据库唯一约束；状态机（已处理则直接返回）。

### 26. 跨服务事务怎么处理？

**A：** 避免分布式强一致；用 Saga、最终一致性、Outbox 模式、补偿事务。

### 27. 如何设计分子生成/对接任务的异步 API？

**A：** POST 提交任务→返回 `task_id`；GET `/tasks/{id}` 查状态；完成后 GET 结果；队列+Worker 执行长推理。

## 三、数据库（28～39）

### 28. ⭐ MySQL InnoDB 和 MyISAM 区别？

**A：** InnoDB：行锁、事务、MVCC、外键；生产默认 InnoDB。

### 29. 索引类型？什么情况下索引失效？

**A：** B+Tree 聚簇/二级索引；联合索引最左前缀；失效：函数包裹列、`like '%x'`、隐式类型转换。

### 30. ⭐ 慢 SQL 如何排查和优化？

**A：** `EXPLAIN` 看 type/key/rows；加索引；改写 SQL；拆大查询；读写分离。

### 31. 事务 ACID 是什么？

**A：** 原子性、一致性、隔离性、持久性。

### 32. MySQL 默认隔离级别？幻读如何解决？

**A：** 可重复读（RR）；InnoDB 用 MVCC + 间隙锁。

### 33. ⭐ PostgreSQL 和 MySQL 选型差异？

**A：** PG：JSONB、GIS、复杂查询、扩展强；MySQL：生态广、运维成熟。生化数据复杂查询/JSON 字段 PG 常见。

### 34. MongoDB 适用场景？

**A：** 文档型、 schema 灵活、非结构化/半结构化实验数据、快速迭代。

### 35. ⭐ Redis 数据类型及应用场景？

**A：** String 缓存/计数；Hash 对象；List 队列；Set 去重；ZSet 排行榜/延迟队列。

### 36. 缓存穿透、击穿、雪崩及解决方案？

**A：** 穿透→布隆过滤器/空值缓存；击穿→互斥锁/逻辑过期；雪崩→TTL 随机、多级缓存、熔断。

### 37. Redis 分布式锁如何实现？

**A：** `SET key NX EX` + Lua 脚本安全释放；Redlock 多节点。

### 38. 如何设计大规模生化化合物数据的存储？

**A：** 结构化部分 RDBMS；大字段/指纹向量 PG+JSONB 或 Mongo；检索索引 Elasticsearch；文件 S3+元数据表。

### 39. 分库分表策略？

**A：** 垂直拆库；水平按 ID/时间分片；中间件路由；分布式 ID（雪花）。

## 四、Docker 与 Kubernetes（40～49）

### 40. ⭐ Docker 镜像和容器的区别？

**A：** 镜像是只读模板；容器是运行实例。

### 41. Dockerfile 常见指令？

**A：** FROM、COPY、RUN、CMD/ENTRYPOINT、EXPOSE、ENV、WORKDIR。

### 42. 如何减小 Docker 镜像体积？

**A：** 多阶段构建；Alpine/slim 基础镜像；合并 RUN；`.dockerignore`。

### 43. ⭐ Kubernetes 核心组件？

**A：** API Server、etcd、Scheduler、Controller Manager；Node 上 kubelet、kube-proxy；Pod 是最小调度单元。

### 44. Deployment 和 StatefulSet 区别？

**A：** Deployment 无状态；StatefulSet 有稳定网络标识和持久卷，适合有状态服务。

### 45. Service 几种类型？

**A：** ClusterIP、NodePort、LoadBalancer；集群内/外访问。

### 46. ⭐ 如何在 K8s 上部署 ML 推理服务？

**A：** Deployment 多副本 + Service；GPU 用 `nvidia.com/gpu` 资源请求；HPA 按 CPU/QPS 扩缩；ConfigMap/Secret 管配置。

### 47. ConfigMap 和 Secret 区别？

**A：** ConfigMap 存配置；Secret 存敏感信息（base64，需 RBAC 保护）。

### 48. Pod 健康检查 liveness 和 readiness 区别？

**A：** liveness 失败重启容器；readiness 失败从 Service 摘除，不接收流量。

### 49. 滚动更新和蓝绿/金丝雀发布？

**A：** RollingUpdate 逐步替换；蓝绿两套环境切换；金丝雀先小流量验证。

## 五、CI/CD 与 DevOps（50～57）

### 50. ⭐ CI 和 CD 分别是什么？

**A：** CI：持续集成，自动构建测试；CD：持续交付/部署，自动发布到环境。

### 51. Jenkins Pipeline 基本概念？

**A：** 流水线阶段：checkout → build → test → deploy；Jenkinsfile 声明式/脚本式。

### 52. GitLab CI 的 `.gitlab-ci.yml` 做什么？

**A：** 定义 stages/jobs、runner、artifacts；MR 触发流水线。

### 53. 如何做 Docker 镜像的 CI 构建与推送？

**A：** build → tag（git sha）→ push 到 Harbor/ECR → K8s 更新镜像 tag。

### 54. 单元测试在 CI 中如何集成？

**A：** pytest/go test 作为 pipeline 必过阶段；覆盖率阈值；失败阻断合并。

### 55. 如何实现多环境（dev/staging/prod）部署？

**A：** 分支策略 + 不同 namespace/values.yaml；人工审批 prod；配置与密钥分离。

### 56. Git Flow 和 Trunk-Based 区别？

**A：** Git Flow：develop/feature/release 分支；Trunk-Based：主干频繁集成，feature flag。

### 57. 线上回滚策略？

**A：** K8s rollout undo；保留上一版镜像；数据库迁移需可逆或向前兼容。

## 六、云平台 AWS/Azure/GCP（58～65）

### 58. ⭐ IaaS、PaaS、SaaS 区别？

**A：** IaaS 虚拟机/网络；PaaS 托管运行时；SaaS 直接用应用。

### 59. AWS 上如何部署容器化后端？

**A：** ECS/EKS；或 Lambda（轻量）；RDS 数据库；S3 对象存储；ALB 负载均衡。

### 60. 对象存储 S3 适用场景？

**A：** 模型文件、化合物库文件、备份、静态资源；预签名 URL 临时访问。

### 61. 云数据库 RDS 的优势？

**A：** 自动备份、主从、补丁、监控；减少 DBA 负担。

### 62. 什么是弹性伸缩（Auto Scaling）？

**A：** 按 CPU/QPS/自定义指标自动增减实例；推理服务波峰波谷常用。

### 63. VPC 和安全组作用？

**A：** 网络隔离；安全组控制入站出站规则；最小权限原则。

### 64. 云上密钥如何管理？

**A：** AWS Secrets Manager / Azure Key Vault；不硬编码；K8s Secret + 外部密钥管理。

### 65. 多云和混合云挑战？

**A：** 一致性、成本、网络延迟、运维复杂度；用 K8s 抽象部分差异。

## 七、AI/ML 后端集成（66～77）

### 66. ⭐ 什么是 MLOps？

**A：** ML 模型的开发、部署、监控、重训练全生命周期工程化；版本、回滚、A/B。

### 67. 模型服务化常见架构？

**A：** 嵌入式（进程内加载）；Sidecar；独立推理微服务 + API Gateway；批处理 vs 在线推理。

### 68. 在线推理和批量推理区别？

**A：** 在线低延迟单条/小批；批量高吞吐离线任务；药物虚拟筛选常批量。

### 69. ⭐ 如何处理 ML 推理的长耗时任务？

**A：** 异步任务队列（Celery/RQ/Kafka）；任务状态轮询；Webhook 回调；超时与取消。

### 70. 模型版本如何管理？

**A：** 模型注册表（MLflow）；镜像 tag；API 路径或 Header 指定版本；灰度发布。

### 71. GPU 推理服务需要注意什么？

**A：** GPU 资源隔离；批大小；CUDA 版本；冷启动；多模型共享 GPU（MPS/动态批处理）。

### 72. 什么是 Graph Neural Network（GNN）？后端如何对接？

**A：** 图结构数据（分子图）上的神经网络；后端通过 Python 推理服务或 TorchServe/Triton 暴露 gRPC/HTTP。

### 73. ⭐ LLM 接入后端的最佳实践？

**A：** API Key 环境变量；Prompt 模板化；结构化输出 JSON；限流、重试、超时；Token 用量监控；敏感数据脱敏。

### 74. 分子生成/对接 API 如何设计输入输出？

**A：** 输入：SMILES/SDF、约束条件；输出：分子列表、分数、对接 pose；大结果异步+对象存储链接。

### 75. 如何监控模型线上表现（漂移）？

**A：** 输入分布监控、预测延迟、错误率；定期与标注集对比；触发重训练告警。

### 76. Knowledge Graph 在后端如何存储和查询？

**A：** 图数据库 Neo4j/JanusGraph；或 RDF+SPARQL；API 层封装 Cypher 查询。

### 77. AI 服务如何做限流和熔断？

**A：** 网关令牌桶；推理队列长度上限；熔断降级返回缓存/默认响应。

## 八、ETL 与大数据（78～87）

### 78. ⭐ ETL 是什么？在药物数据场景的典型流程？

**A：** Extract 抽取（PubChem/ChEMBL/实验数据）→ Transform 清洗标准化 → Load 入库；去重、单位统一、SMILES 校验。

### 79. ETL 管道如何保证数据质量？

**A：** Schema 校验、空值规则、范围检查、与源系统对账、数据血缘记录。

### 80. 增量同步和全量同步如何选择？

**A：** 增量：按时间戳/CDC，省资源；全量：初始化或修复；大表常增量+定期全量校验。

### 81. Apache Spark 适用场景？

**A：** 分布式大规模数据清洗、特征工程、TB 级化合物库处理。

### 82. Spark 和 Flink 区别？

**A：** Spark 批处理为主（微批流）；Flink 真流式、低延迟；实时告警用 Flink 多。

### 83. 消息队列 Kafka 在数据管道中的作用？

**A：** 解耦生产消费、削峰、持久化、多订阅者；ETL 各阶段异步串联。

### 84. 如何处理 PB 级文件存储与检索？

**A：** 对象存储 + 元数据索引；分区目录；Parquet/ORC 列式格式；Spark 并行读。

### 85. 数据血缘（Data Lineage）是什么？

**A：** 记录数据从哪来、经过哪些变换；合规与排错必备。

### 86. CDC（Change Data Capture）是什么？

**A：** 捕获数据库变更流（binlog）实时同步到数仓/缓存。

### 87. 生化数据常见格式 SMILES/SDF/MOL2 了解吗？

**A：** SMILES 字符串表示分子；SDF 结构文件批量；后端需校验解析库（RDKit）集成。

## 九、测试、性能与安全（88～95）

### 88. ⭐ 单元测试和集成测试区别？

**A：** 单元测单函数/类，Mock 外部依赖；集成测多模块联调、真实 DB/HTTP（testcontainer）。

### 89. pytest 常用 fixture 作用？

**A：** 测试前置/后置；共享 DB、客户端；`conftest.py` 组织。

### 90. 如何对 API 做集成测试？

**A：** TestClient（FastAPI）；httpx；启动 test DB；断言状态码与 JSON schema。

### 91. ⭐ 性能调优从哪几层入手？

**A：** SQL/索引；缓存；异步/连接池；算法复杂度；水平扩展；Profiling（cProfile/py-spy）。

### 92. 什么是 APM？常用工具？

**A：** 应用性能监控；Prometheus+Grafana、Datadog、Jaeger 链路追踪。

### 93. API 安全：OAuth2/JWT 流程？

**A：** 登录换 token；Bearer 头；过期刷新；RBAC 权限控制。

### 94. 如何防止 SQL 注入？

**A：** 参数化查询/ORM；禁止拼接 SQL；最小权限 DB 账号。

### 95. 敏感数据（化合物/IP）如何保护？

**A：** 传输 HTTPS；存储加密；访问审计；租户隔离；脱敏日志。

## 十、系统设计 & 综合（96～100）

### 96. ⭐ 设计一个「药物对接任务提交与查询」系统

**A：**  
- 客户端 POST `/docking/jobs`（受体+配体）→ 入 Kafka/Redis Queue → Worker GPU 跑对接 → 结果写 S3+PG  
- GET `/docking/jobs/{id}` 查状态  
- K8s Deployment Worker 可 HPA  
- 鉴权、限流、幂等、监控告警

### 97. 设计高可用后端架构要点？

**A：** 多副本、无单点、健康检查、熔断限流、DB 主从、备份、多 AZ、灰度发布。

### 98. 如何与算法团队、化学家协作？

**A：** 明确 API 契约（OpenAPI）；版本化模型；文档与示例；定期联调；反馈线上 bad case。

### 99. 为什么想加入 AI 制药公司？你的优势？

**A（模板）：** 后端+数据处理经验；有 API 集成、ETL、Docker 部署实践；对 AI+科学交叉感兴趣；学习能力强；可举例量化台/数据流水线项目。

### 100. 英文技术文档读写如何应对？

**A：** 阅读官方文档、论文 Abstract；写作 API doc、Design doc、PR description；简历可提 CET/项目英文文档经验。
